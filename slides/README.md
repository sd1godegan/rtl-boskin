# Folder Slide

Folder ini menyimpan file PDF slide presentasi untuk setiap RTL.

## Daftar File

| RTL | Nama File |
|---|---|
| Digitalisasi Pembelajaran | `digitalisasi-pembelajaran.pdf` |
| Tata Kelola Sekolah (SPMI) | `tata-kelola-spmi.pdf` |
| Literasi & Numerasi | `literasi-numerasi.pdf` |

## Cara Menambah Slide Baru

1. Ekspor slide ke format PDF.
2. Beri nama file dengan huruf kecil, gunakan tanda hubung (`-`) sebagai pemisah.
3. Unggah ke folder ini.
4. Daftarkan di `data.js` pada field `slide:`.

## Catatan

- Nama file **case-sensitive** di GitHub Pages — pastikan sama persis dengan yang di `data.js`.
- Hindari spasi pada nama file (gunakan `-`).
- Ukuran PDF disarankan di bawah 20 MB agar cepat dimuat.
